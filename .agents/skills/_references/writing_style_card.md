# 写作风格卡（rewrite-style 的唯一依据）

来源：14 篇华为杯国一论文语料的实测分布（`corpus_stats.md`），以及与 draft 输出稿的对照。所有阈值是"优秀论文 P75"，不是绝对标准；样本增加后重新统计。

## 1. 一句话原则

> 用完整的因果句讲清"为什么这样做 → 怎么做 → 得到什么 → 意味着什么"，术语只在首次出现时定义，之后直接使用。

## 2. 硬指标（prose_lint 强制）

| 指标 | 目标（≤ 语料 P75） | 典型 draft 稿 | 怎么改 |
| --- | ---: | ---: | --- |
| 全角括号 / 千字 | 5.6 | 11–15 | 括号里的完整句 → 独立句；数值补充 → 进表格；缩写标注只保留首次 |
| 中文引号 / 千字 | 2.2 | 10.7 | 术语首次定义用引号，之后去引号；方法名不加引号 |
| 破折号 / 千字 | 0.11（max 0.28） | 1.7–2.7 | 禁止 `A—B—C` 名词串；破折号只用于插入语，且每千字不超过 1 处 |
| 英文缩写 / 千字 | 3.3 | 15 | 首次出现"中文全称（英文缩写）"，正文优先用中文名；一句话不超过 3 个缩写 |
| 单个"问题 N"章节汉字 | ≥ 3.3k（P25） | 1.5k–3k | 不是灌水：按处理链补缺环（见 `problem_chain_template.md`） |
| 三级节正文 | ≥ 300 字 | 56–230 | 并入上级节改为段落，或与相邻小节合并 |
| 二级标题总数 | ≤ 24 | 36 | 合并"特征组 A / B / C"式碎节 |
| 四级标题 | 0 | — | 一律改成段落首句 |

连接词密度（首先/从而/此外/可以看出…）语料中位 3.4/千字，draft 稿 1.0。**不要为了达标堆连接词**，它只是"论证是否展开"的代理指标：句子之间有因果关系时自然会出现这些词。

## 3. 句法改写模板

### 3.1 名词串 → 因果句

坏：
> 采用"谱峭度共振带—Hilbert 包络—等转数分窗（16 转，50% 重叠）—阶次谱"流水线提取特征。

好：
> 特征提取分四步。先用谱峭度在频域上定位冲击能量最集中的共振带，只保留该带内的信号以抑制无关振动；再对带通信号做 Hilbert 变换得到包络，使故障冲击的重复频率显露出来；随后按转速把包络切成每 16 转一段、相邻段重叠一半的窗，使不同转速下的样本长度在"转数"意义上一致；最后对每段做阶次谱，把频率轴换成相对于转频的阶次轴，这样特征就不再随转速变化。

要点：每个步骤一句，说明它解决什么问题；参数（16 转、50%）放进句子而不是括号。

### 3.2 括号补充 → 独立句或表格

坏：
> 对标准化信号计算峭度、偏度、峰值因子（max|x̃|/RMS）、脉冲因子、裕度因子、波形因子、过零率与 16 段能量分布熵（共 8 维）。

好：
> 时域统计特征共 8 维，全部对标准化后的信号计算，因而只反映波形的形状而不含幅值量级。其中峭度和偏度刻画分布的尖峭与偏斜；峰值因子、脉冲因子、裕度因子、波形因子是峰值、均值、方根幅值与均方根之间的不同比值，从多个角度衡量冲击相对于背景的突出程度；过零率反映主导频率的高低；把信号等分为 16 段后计算能量分布熵，用来衡量冲击是否集中在少数时间段。

### 3.3 引号术语 → 定义一次，之后直用

首次：
> 本文把每个故障位置在源域中距离最近的传感器通道称为近端通道。

之后：
> 按近端通道筛选后，源域样本从 161 个文件缩减到 165 段信号。

### 3.4 公式周边

公式前一句说清要建立什么关系、为什么；公式后必须有"其中……"解释每个新符号，再用一句话说直观含义或取值范围。示例：

> 为使不同转速下的样本可比，把频率轴换成阶次轴：
> $$o = f / f_r$$ {#eq:order}
> 其中 $f$ 为频率，$f_r$ 为转频。阶次 $o$ 表示每转发生的振动次数，故障特征阶次只由轴承几何决定，与转速无关。

### 3.5 图表周边

图/表前一句：看什么、预期看到什么。图/表后至少两句：数据显示了什么、说明了什么、与预期或基线比如何。禁止"如图 5 所示"后直接换节。

### 3.6 结果回到题意

每一问结尾一段：用题目的语言复述结论（"目标域的 12 个待诊断样本中……"），说明可信度来源（哪一项检验支撑），并给出对下一问的输入是什么。

## 4. 允许 / 禁止

允许：
- 拆句、合句、换连接词、调整段落顺序、合并小节、增加过渡句与解释句；
- 用 `reports/`、`results/`、图表 README、代码 docstring 里已有的数字和事实扩写；
- 给公式补符号解释、给图表补引导与解读。

禁止：
- 改任何数字、单位、公式、图表编号、引用标签（fact_diff 强制）；
- 新增原稿和 draft 报告中不存在的实验、指标、结论；
- 删去限定条件（"在源域上""在假设 3 下"）以让结论显得更强；
- 出现 `reports/`、`figures/`、`run_all`、`AGENTS.md` 等内部名称；
- 使用 `anti_ai_patterns.md` 中列出的措辞。
